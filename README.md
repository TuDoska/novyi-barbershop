# NOVYI_ BARBERSHOP — сайт барбершопу (Стрий)

Мінімалістичний сайт у стилі luxury для барбершопу NOVYI_ у Стрию.

**Демо:** https://tudoska.github.io/novyi-barbershop/

## Що є
- Hero з анімованою типографікою та золотими акцентами
- Прайс з перемикачем рівня майстра (Top / Prime) і фільтром категорій
- Картки майстрів (чорно-біле фото → колір при наведенні)
- Етапи візиту, рейтинг, контакти з мапою
- Онлайн-запис через EasyWeek, плаваюча кнопка запису на мобільному
- SEO: meta, Open Graph, schema.org `BarberShop`
- Адаптив від 320 px, `prefers-reduced-motion`

## Стек
HTML, CSS (Grid, custom properties), vanilla JavaScript. Без збірки.

Дані (послуги, ціни, майстри) — у `js/data.js`.
