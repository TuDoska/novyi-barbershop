# NOVYI_ BARBERSHOP — сайт з онлайн-записом

Сайт барбершопу NOVYI_ у Стрию в стилі luxury-мінімалізм: власний онлайн-запис, кабінет клієнта, панель адміністратора й майстрів, аналітика заробітку.

**Сайт:** https://novyi-barbershop.onrender.com

## Можливості
**Клієнт**
- Запис за 4 кроки: майстер → послуга → дата → вільний час (зайняте не показується, враховується тривалість)
- Акаунт за телефоном і паролем; кнопка «показати пароль»
- Кабінет: кількість візитів, історія, найближчі записи зі скасуванням
- Таймер до наступної стрижки (від останнього візиту + обраний інтервал)
- Зміна імені й телефону раз на добу, зміна пароля (інші сесії виходять)

**Майстер** — бачить і веде лише свої записи, створює записи по телефону.

**Адмін**
- Записи всіх майстрів: підтвердити / виконано / не прийшов / скасувати, фінальна сума для «від»-послуг
- Заробіток: сьогодні, тиждень, місяць, графік по днях, по майстрах і послугах, середній чек
- Клієнти (пошук, блокування), послуги й ціни, майстри, акаунти персоналу, графік і вихідні дати

## Безпека
bcrypt-паролі · JWT у httpOnly cookie · блокування після 5 невдалих входів · rate limiting · Helmet CSP · перевірка Origin (CSRF) · валідація типів (NoSQL-ін'єкції) · ролі на сервері · ціни й слоти рахує сервер · ліміт 2 активних записи на клієнта.

## Стек
Node.js, Express, MongoDB (Atlas) / NeDB локально, vanilla JS, CSS.

## Запуск
```bash
npm install
ADMIN_PHONE=0739012596 npm run dev   # http://localhost:3000
npm test                              # 11 інтеграційних тестів
```
Змінні середовища: `MONGODB_URI`, `MONGODB_DB`, `JWT_SECRET`, `ADMIN_PHONE` (номер, який при реєстрації стає адміном).
